# Power BI: Анализ эффективности скидочной политики

## О проекте

Анализ влияния скидок на прибыль розничной сети.  
Дашборд позволяет отслеживать динамику продаж, прибыльность по категориям и выявлять убыточные зоны.

**Стек:** Power BI, DAX, Power Query, Excel

**Данные:** 5 таблиц, 100K+ строк

## Ключевые меры DAX

- Общий объем продаж, Общая прибыль, Маржинальность
- Динамика продаж год к году (YOY %), Продажи с начала года (YTD), Прибыль с начала года (YTD)
- % убыточных транзакций
- Эффективность скидки (прибыль на 1% скидки)

## Бизнес-выводы

> Скидка >25% в категории Electronics снижает маржинальность

- Декабрь 2023 vs 2022: +35% продаж (YOY)
- Доля убыточных транзакций: ~8%
