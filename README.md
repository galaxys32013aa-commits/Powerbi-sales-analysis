# Powerbi-sales-analysis
Анализ эффективности скидочной политики розничной сети. Включает: ETL в Power Query (5 таблиц, 100K+ строк), 17 мер DAX (включая YOY, YTD долю убытков), авторскую метрику эффективности скидки. Выявлено, что скидки >25% в категории Electronics снижают маржинальность на 8 процентных пунктов
